Cara Membuat File Soal (format file .json)

1. Buat file teks baru → simpan dengan nama soal.json

2. Salin kode di bawah ini → tempel ke file tersebut

{
  "easy": [
    {
      "q": "Ibukota Indonesia adalah ...",
      "o": ["Jakarta", "Surabaya", "Bandung", "Medan"],
      "c": 0
    },
    {
      "q": "1 + 1 = ?",
      "o": ["1", "2", "3", "4"],
      "c": 1
    }
  ],
  "hard": [
    {
      "q": "Hasil dari 12 × 15 = ?",
      "o": ["160", "170", "180", "190"],
      "c": 2
    }
  ]
}

Penjelasan:

  • easy → soal mudah, benar = 1 langkah
  • hard → soal sulit, benar = 2 langkah
  • q → pertanyaan
  • o → 4 pilihan jawaban (A B C D)
  • c → indeks jawaban benar: 0=A, 1=B, 2=C, 3=D

❓ PANDUAN PENGGUNAAN

ArTTiS — Arena Tarik Tambang Informatika Style

1. Menyiapkan Soal (pilih salah satu)

  • Upload File .json — isi Nama Mapel/Sesi & Bahasa Soal, lalu pilih file .json (format lihat di bawah).
  • Bank Soal Tersimpan — soal yang pernah diupload/dibuat otomatis tersimpan di perangkat ini, tinggal pilih & klik "Muat".
  • Generator AI (Gemini, gratis) — klik "🤖 Buka Generator Soal AI", masukkan API Key pribadi (ambil gratis di aistudio.google.com/apikey), isi topik, lalu Generate.

2. Format File Soal (.json)

{
  "easy": [{ "q": "Ibukota Indonesia?", "o": ["Jakarta","Surabaya","Bandung","Medan"], "c": 0 }],
  "hard": [{ "q": "12 × 15 = ?", "o": ["160","170","180","190"], "c": 2 }]
}

c = indeks jawaban benar (0=A, 1=B, 2=C, 3=D). Soal easy menarik tali 1 langkah, hard 2 langkah. Tidak mau bikin manual? Klik "Download Contoh File .json" di halaman utama.

3. Mengatur Sesi

  • ⏱️ Durasi per Soal — geser 5–30 detik.
  • 🏁 Mode Per-Match — Sekali Tarik, atau Best of 3/5/7 ronde.
  • 👥 Jumlah Tim — 2 Tim (biasa) atau 4/8 Tim (Mode Turnamen sistem gugur).
  • 🌐 Bahasa Soal — penanda Indonesia/English/Campuran, juga dipakai Generator AI.
  • ⏳ Batas Waktu Pertandingan — opsional, 5–30 menit. Kalau dua tim sama kuat dan tarik ulur terus, begitu waktu habis pemenang otomatis ditentukan dari posisi tali terakhir.

4. Menjalankan Pertandingan

  1. Cek dulu soal lewat layar Preview Soal, lanjutkan kalau sudah sesuai.
  2. Baca Peraturan Permainan, klik "Saya Mengerti, Mulai!".
  3. Siswa menjawab lewat tombol A/B/C/D di sisi timnya masing-masing sebelum waktu habis.
  4. Jawaban benar menarik tali ke timnya; salah/waktu habis membuat tali maju ke tim lawan.

5. Fitur Pendukung

  • 📺 Mode Tampilan — pilih dari dropdown, 7 tingkat: Paling Kecil, Lebih Kecil, Kecil, Normal, Sedang, Besar, Sangat Besar. Level Sedang ke atas otomatis masuk layar penuh; level Kecil ke bawah cocok untuk layar sentuh besar yang justru terasa terlalu penuh di ukuran Normal.
  • 🙈/👁️ Sembunyikan Tombol — tombol di pojok kanan bawah untuk menyembunyikan semua tombol mengambang lain (biar tidak mengganggu tampilan saat presentasi/dokumentasi). Tombol ini sendiri selalu terlihat sebagai jalan kembali.
  • ☀️ Light Mode — beralih ke tema terang, cocok untuk ruangan yang terang/proyektor kurang gelap.
  • 🐢 Hemat Performa — aktifkan kalau animasi terasa patah-patah (biasa terjadi di TV/IFP dengan GPU terbatas). Mematikan efek blur & animasi berat, tampilan tetap rapi tapi jauh lebih ringan.
  • 🏆 Riwayat — rekap pertandingan, skor, dan soal tersulit; bisa diekspor ke PDF/Excel.
  • 📲 Install App — pasang ArTTiS seperti aplikasi biasa, tetap jalan walau offline (kecuali Generator AI).

💡 Tips: simpan soal ke Bank Soal setiap kali membuat set baru — sangat menghemat waktu untuk kelas paralel dengan materi sama.

Cara Bermain

  1. Kelas dibagi jadi Tim A dan Tim B (atau lebih kalau Mode Turnamen).
  2. Perhatikan layar — akan muncul soal pilihan ganda dengan 4 pilihan (A, B, C, D).
  3. Diskusikan jawaban dengan timmu secepat mungkin, ada batas waktu di tiap soal!
  4. Klik tombol jawaban di sisi timmu sebelum waktu habis.
  5. Jawaban benar menarik tali ke arah timmu. Jawaban salah malah membuat tali maju ke tim lawan!
  6. Tim yang berhasil menarik tali sampai batas kemenangan, menang! 🎉

Apakah ArTTiS berbayar?

Tidak, sepenuhnya gratis. Generator Soal AI memakai jatah gratis dari Google Gemini.

Apakah data soal & riwayat tersimpan di internet?

Tidak. Semua tersimpan lokal di browser perangkat masing-masing, tidak otomatis sinkron antar perangkat.

Kenapa Generator Soal AI gagal terus?

Biasanya API Key salah/kadaluarsa, atau batas gratis harian tercapai. Coba lagi beberapa saat kemudian.

Bisa dipakai tanpa internet?

Bisa untuk sebagian besar fitur, asalkan ArTTiS pernah dibuka online sekali sebelumnya. Generator AI tetap butuh internet.

Berapa maksimal jumlah tim?

2 tim untuk mode biasa. Mode Turnamen mendukung 4 atau 8 tim sistem gugur.

Animasinya patah-patah / layar suka ke-zoom sendiri di layar sentuh besar (IFP)?

Aktifkan "🐢 Hemat Performa" kalau perangkat terasa berat (biasa terjadi di IFP dengan GPU terbatas). Zoom tak sengaja saat banyak peserta menyentuh layar bersamaan juga sudah dicegah otomatis.

PERATURAN PERMAINAN

  • Dua tim akan saling bertanding menjawab soal pilihan ganda
  • Setiap jawaban benar = tarik 1 langkah (atau 2 langkah untuk soal sulit)
  • Setiap jawaban salah = lawan maju 1 langkah
  • Waktu menjawab tiap soal hanya 10 detik
  • Pemenang ronde ditentukan dari posisi tali yang berhasil ditarik ke sisi timnya
