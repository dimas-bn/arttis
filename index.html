Cara Membuat File Soal (format file .json)

1. Buat file teks baru → simpan dengan nama soal.json

2. Salin kode di bawah ini → tempel ke file tersebut

{
  "easy": [
    {
      "q": "Ibukota Indonesia adalah ...",
      "o": ["Jakarta", "Surabaya", "Bandung", "Medan"],
      "c": 0
    },
    {
      "q": "1 + 1 = ?",
      "o": ["1", "2", "3", "4"],
      "c": 1
    }
  ],
  "hard": [
    {
      "q": "Hasil dari 12 × 15 = ?",
      "o": ["160", "170", "180", "190"],
      "c": 2
    }
  ]
}

Penjelasan:

  • easy → soal mudah, benar = 1 langkah
  • hard → soal sulit, benar = 2 langkah
  • q → pertanyaan
  • o → 4 pilihan jawaban (A B C D)
  • c → indeks jawaban benar: 0=A, 1=B, 2=C, 3=D

🏆 RIWAYAT PERTANDINGAN

PERATURAN PERMAINAN

  • Dua tim akan saling bertanding menjawab soal pilihan ganda
  • Setiap jawaban benar = tarik 1 langkah (atau 2 langkah untuk soal sulit)
  • Setiap jawaban salah = lawan maju 1 langkah
  • Waktu menjawab tiap soal hanya 10 detik
  • Pemenang ditentukan dari posisi tali yang berhasil ditarik ke sisi timnya
